# Product requirements / Phase 0 scope
Authority: master-specification.md, version 1.0, plus owner instructions. Initial goal: compare a genuine District 15 new launch against a genuine resale project using licensed, attributable transactions and explicit dated cash flows. No portal scraping or paid inference.

Phase 0 delivers structure, documented boundaries, schemas, demo fixtures, local UI, tested calculation primitives, source feasibility and CI definitions. It does not establish real-data MVP acceptance. Never promote synthetic rows into evidence.

MVP gates: official source ingested with provenance and completeness report; canonical genuine project identities; validated PSF; dated regulatory rules; construction drawdowns and mortgage ledger; 5/10-year bear/base/bull scenarios; net profit, yield, equity IRR and break-even; comparable evidence with uncertainty; leakage-safe validation; security and redistribution review; explicit production approval.

Demo acceptance: fresh npm ci, lint/typecheck/tests/build pass; Python contracts pass; HTML and compiled JS served locally; fixture labels persist through shared schema and API. Database application and hosted CI remain separate checks until executed.
